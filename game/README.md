# نور: حارس الواحة — لعبة منصات 2D عربية لأندرويد

**الحالة:** مكتملة وقابلة للعب — APK حقيقي موقع وقابل للتثبيت: `game-noor-oasis.apk`

## اللعبة
- البطل: **نور**، حارس الواحة — 8 حركات (وقوف/مشي/قفز/سقوط/هجوم/إصابة/موت/فوز).
- 3 مراحل: واحة النخيل، كهف البلور (منصات متحركة)، عرش الرمال + الزعيم **تنين الرمال**
  (3 هجمات: وابل كرات نارية، انقضاض، استدعاء خفافيش).
- أعداء: غيلان رمال (دورية/مطاردة)، خفافيش غاطسة. قفز فوقهم أو اضربهم بالسيف.
- شظايا الشمس (عملات)، قلوب، مزهريات سرية قابلة للكسر، نقاط حفظ، بوابة نهاية
  (مغلقة حتى هزيمة الزعيم في المرحلة 3).
- اندفاع (Dash) مع تباطؤ، Coyote-time وJump-buffer لإحساس احترافي.
- قصة عربية + مقدمة بتعليق صوتي (TTS عربي، أو ضع `assets/voice/intro.wav` و`win.wav` لتجاوزه).
- قوائم عربية RTL: رئيسية/اختيار مراحل/إعدادات (3 مستويات صوت)/حول/إيقاف/فوز/خسارة.
- حفظ: المراحل المفتوحة + أفضل حصيلة + الإعدادات (SharedPreferences).
- موسيقى ومؤثرات مولّدة إجرائيًا — حجم APK ≈ 50KB فقط.

## التحكم (لمس)
◀ ▶ حركة — **قفز** — **هجوم** — **دفع** (اندفاع) — زر II للإيقاف. (لوحة المفاتيح تعمل أيضًا على المحاكي).

## البناء (بدون Gradle — aapt2 مباشرة)
```bash
cd game && ./build.sh
```
المتطلبات: Android SDK (platform android-35 + build-tools 35) وJDK 17.
المخرجات: `game-noor-oasis.apk` (موقّع، zipaligned، تم التحقق بـ apksigner).

## الاختبار
- اختبار headless لمنطق اللعب: `TestMain` (في `/tmp/opencode/gtest`) — 13/13 ناجح:
  إكمال المراحل، تفعيل الزعيم وقتله، فتح البوابة، النصر، إعادة الظهور.
- التحقق من APK: توقيع سليم + `launchable-activity: com.noor.oasis.MainActivity`.

## القيود المعروفة
- لا يوجد AAB (يتطلب bundletool؛ سكربت البناء الحالي ينتج APK الـ Release المطلوب).
- التعليق الصوتي TTS يعتمد على دعم الجهاز للغة العربية (وإلا يُستخدم صوت افتراضي)؛
  يمكن استبداله بملفات wav أصلية في `assets/voice/`.
- لم يُختبر على جهاز فيزيائي (لا يوجد جهاز متصل) — تم التحقق الاستاتيكي والمنطقي فقط.
